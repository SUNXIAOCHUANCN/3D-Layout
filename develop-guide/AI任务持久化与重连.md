# AI 编辑任务持久化与刷新恢复

## 使用范围

默认“AI 编辑”聊天传输改为后端任务；“LLM Agent 实验”复用同一传输适配器。`?agent=loopback`、外部 WebSocket 模式继续使用原协议，不具备本实现的后端任务恢复能力。CoAgent 布局运行时没有改成后端执行。

在 AI 编辑面板提交一条新指令，刷新后保留场景 URL、对话、已确认工具结果、编辑草稿和待裁决状态。推理请求和工具循环由后端驱动，刷新不会中止该后端任务。首次重连可能等待旧页面租约到期，最长约 8 秒。

本次更新前已经丢失的浏览器内存任务无法恢复；新任务才会进入数据库。

会话按场景和 AI 通道隔离保存。切换场景后，面板立即清空旧对话和任务状态，再恢复目标场景的最新会话；没有会话的场景显示空白。切回原场景可恢复对话、任务与待确认提案，不会取消原任务。旧场景延迟返回的请求不能覆盖当前面板或草稿，清空对话的临时状态也不会带到另一个场景。

初始指令和每次回滚时填写的修改意见都作为独立的用户消息保存在会话中；回滚说明、工具结果和计时为过程消息。未填写意见时记录“回滚本次提案，请继续调整”。模型仍会收到包含回滚边界的完整反馈，但内部提示不冒充用户原话。提交成功后立即更新聊天显示，刷新恢复时一次性加载后端会话，不受原来 200 条实时消息上限影响。

## 修改前后对比

聊天输入旁提供“清除对话”文字按钮，清除当前场景、当前 AI 通道的会话和后续模型上下文，刷新后不再恢复旧消息；场景文档及撤销历史保持不变。后端原子归档相关任务的会话（conversationCleared），内部工具回执保留供诊断。任务仍在执行、等待裁决或暂停时按钮不可用，需要先明确停止任务。接口为 `POST /api/tasks/:id/clear`。

后端任务响应提供提案基线 `before`（只含场景文档，不包含撤销日志）。AI 编辑与 LLM Agent 面板在提案期间将基线与当前草稿按物体 ID 比较，列出新增、删除及位置、旋转、缩放、模型、名称、可见性、颜色、材质和地形变化。位置、旋转和缩放展示前后数值；已撤销的中间操作不计为最终改动。

点击清单聚焦当前物体；删除项聚焦原位置。视口以绿色、红色和蓝色范围框分别标记新增、删除和修改，可关闭高亮或隐藏原位置。范围框使用模型库的米制包围盒（缺失时回退到标准尺寸），应用实例旋转和有符号缩放；它是范围提示，不是模型轮廓的精确重建。框不参与拾取、模型截图和场景导出。刷新或切回场景后从后端基线重建对比；接受、停止及切换场景时清理当前审查显示。当前仅比较物体变化，环境、灯光和相机变化不计入物体清单。

## 执行边界

### 模型上下文与耗时

默认采用原版模型循环：`scene.get_state` 附带完整模型目录，同一场景、通道沿用连续上下文，最多完成 24 轮模型响应。界面的模型检索和疑似重叠检查均为可选能力，默认关闭。启用模型检索后，默认不附带完整目录，通过 `model.search({query, category?, limit?, offset?})` 获取候选（默认 12 项，最多 20 项）；检索使用名称、标签、描述、类别和中英词扩展，不是向量检索。

后端为每轮请求保存 `modelRequests`：序号、开始时间、首次文字输出时间、结束时间、耗时、上下文字符数及完成/失败/取消/超时状态。字符数含可能存在的图片 data URL，不等同于 token 数。面板显示等待秒数、是否已有文字输出及超时上限，30 秒后提示响应较慢；每轮结束在会话中保留耗时记录。只返回工具调用的模型可能没有首次文字时间，不能据此推断服务端没有工作。

原版模式默认不设固定请求超时，可手动停止；兼容旧任务的 proposal 模式默认总超时 180 秒。通过服务端环境变量 `LAYOUT_MODEL_TIMEOUT_MS` 可配置毫秒数，覆盖默认值。超时会中断请求并进入 `paused`，保留记录、预览草稿和工具结果；迟到回复不触发工具，也不自动重试。点击“重试本轮”只重新请求当前模型轮次，任务 ID、工具轮次、已完成回执和模型输入保持连续；重试请求以 requestId 去重。刷新和服务重启后仍可恢复暂停状态，重试时从浏览器重新提供密钥。此前标为 failed 且最后一次模型请求为 timed_out 的任务也显示重试入口。重试会更新工具配置，正式场景版本变化或同场景有其他活动任务时拒绝恢复，防止覆盖。此优化减少上下文负担，不保证模型服务的实际响应时间。

### 服务错误与手动恢复

模型服务恢复：流式错误（含 `data_inspection_failed`）、HTTP 错误、连接失败和流中断带 `MODEL_SERVICE_ERROR` 标识，使任务进入 `paused/service_error`，而非终止并撤销预览。轮询、刷新和重连均不会自动重试。面板保留“重试本轮”和“更换模型设置”，也可直接切换上方档案，再明确点击重试。旧版 failed 且错误为服务流式拒绝的记录也显示恢复入口。

重试请求可携带完整 `settings`（含临时 apiKey），后端验证并替换模型、地址和协议，密钥只进入内存；界面记录模型切换事件。关闭图像输入时删除模型上下文中的附图。任务 ID、草稿、意见和已完成工具回执保留，仅继续当前模型轮次。版本冲突和同场景竞争任务仍会阻止恢复。手动重试不保证服务商会接受同一内容，不会自动修改提示以绕过服务审查。

### 模型输入隔离与活动状态

界面完整保留历史对话。新建的 original 模式任务沿用同场景、同通道上一条 original 任务的模型上下文，包括助手回复和工具结果，不采用最近 6 条、每条 400 字的截断策略。兼容旧 proposal 任务仍保留该精简策略。空回复会暂停并提供手动重试，不自动结束任务。上下文字符数含图片 data URL，不能直接视为模型 token 数；全量目录和图片仍可能导致耗时较长。

OpenAI Chat 适配器上报收到 HTTP 响应头、推理活动、工具流和正文活动，面板区分等待服务响应、已连接等待输出、模型正在推理、正在接收工具调用；只保存活动状态和时间，不收集推理原文。SSE 错误帧直接报错，不再误判为空回复。当前轮次还显示模型输入字符数，便于诊断历史上下文负担；连接前等待和服务端排队的具体原因仍需服务商日志确认。

### 疑似重叠粗筛

`scene.check_overlaps({assetIds?, ignoreAssetIds?, tolerance?, limit?, offset?})` 使用模型库世界包围盒（含旋转和有符号缩放）及地形范围检查当前草稿。默认容差 0.01 米；单纯接触及任一轴重叠不超过容差的配对不报告。返回物体 ID、名称、位置、包围盒、交集范围、三轴尺寸和体积。可只检查修改物体涉及的配对，忽略地板等结构，并分页查询（默认 30、最多 100）。隐藏物体不参与，缺失元数据的物体单独报告，不能默认为通过。

包围盒只是粗筛，旋转、空心或复合模型可能误报；零结果、截图和点选均不能证明“无穿模”。模型收到这一限制，不应把疑似重叠当作已确认碰撞，也不应只凭截图断言全部校验通过。

```text
AI 编辑面板 → POST /api/tasks → SQLite 任务检查点
                                  ↓
                             后端调用模型
                                  ↓
                    持久化工具编号和参数，等待浏览器
                                  ↓
        浏览器取得租约 → 执行工具 → IndexedDB 写回执和草稿
                                  ↓
                  后端原子记录结果及草稿，继续模型循环
                                  ↓
                      写工具批次 → 人工裁决 / 自动提交
                                  ↓
                    工作区幂等提交 → 前端重新加载已保存状态
```

浏览器继续负责场景工具执行，包括视口截图和拾取。页面不存在时，后台推理可以继续，但到达需要浏览器的工具时暂停等待重连；不会假装已经执行。浏览器完成工具后的草稿不会立即覆盖正式场景，当前批次接受并提交成功后才进入正式撤销历史。

## 数据记录

`ai_tasks` 位于现有 `.data/layout.sqlite`，通过幂等建表安装，不改现有工作区结构。每个任务保存：

- 场景、通道、用户指令、创建时间和状态；
- 模型配置（不含 API Key）、提示词、工具 schema、对话上下文；
- 对话、节流持久化的流式文字、模型轮次；
- 稳定工具编号、模型原始调用 ID、参数、权限、结果和完成时间；
- 初始工作区版本、已确认草稿、浏览器身份、租约和代次；
- 待确认提交的完整幂等请求，用于提交窗口的崩溃恢复。

密钥仅在当前后端进程内存中保存，任务结束或服务关闭后清除。数据库恢复时未完成任务进入 `awaiting_credentials`；前端从本机已有模型配置重新提供密钥后继续，不把密钥写入任务表。任务记录包含用户指令、场景和截图，备份数据库时应视为项目数据。

旧浏览器传输保留用于兼容；默认后端传输的任务记录以 `ai_tasks` 为准，不再依赖浏览器 recorder 或旧实验插件每轮文件日志。模型可见工具不包含旧的 `log.*` 导出工具，完整调用记录由后端任务表保存。

## 状态

| 状态 | 含义 |
|---|---|
| running | 后端模型推理或继续调度 |
| awaiting_browser | 已发出工具调用，等待持有租约的浏览器执行 |
| awaiting_user | 草稿已完成，等待接受或拒绝 |
| paused | 模型超时、空回复或服务错误，保留草稿，等待明确重试或停止 |
| awaiting_credentials | 后端重启后等待重新提供密钥 |
| completed | 正常完成，接受的修改已入库 |
| cancelled | 用户明确停止任务 |
| conflict | 基础版本过期，拒绝覆盖其他编辑 |
| failed | 模型或执行流程出错，记录仍可查询 |

关闭面板或卸载传输只断开连接，保留后端任务；“停止生成”才调用取消 API。新建任务前，后端检查同场景其他未完成任务，避免并发 AI 草稿互相覆盖。

默认 original 模式在每批写工具完成后等待裁决：接受会保存本批并继续模型循环；拒绝只回滚本批，之前已接受的批次仍保留。保留提案继续修改则保留当前草稿并把意见反馈给模型。裁决携带 reviewVersion，避免旧按钮或重复请求作用于下一批。只有明确停止才取消任务，尚未提交的草稿随之撤销。

旧 proposal 模式继续兼容：接受最终提案后结束任务，revised 保留整套草稿，rejected 回滚整个未提交提案。两种模式都持久化对话与意见；模型文字不能作为保存成功的凭据，只有数据库确认提交后程序才显示已保存。

## 去重与安全恢复

工具调用编号由任务、轮次和调用位置组成，刷新不会改变。浏览器先写 issued 标记，再执行，再将结果与草稿存入 IndexedDB，最后提交后端。后端将结果和草稿放在同一行检查点更新中；重复结果只确认已存在回执，不重新执行工具。

普通编辑在未提交草稿中执行。若浏览器在本地执行后、保存回执前退出，新页面从最后确认草稿恢复，再执行这次未确认编辑，不会在正式场景上重复累加。

生成和导出类工具有外部副作用。若发现 issued 标记但没有完成回执，恢复时要求用户确认是否重新执行；拒绝后以失败结果回告模型，不盲目重放。不能保证在没有外部系统幂等支持时绝对消除副作用不确定性，因此明确暂停处理。

同一任务同时只有一个浏览器租约。租约到期换页会增加 epoch；旧页面回执被拒绝。截图所属的 epoch 仅在当前页面记录，新页面不能复用旧图坐标直接拾取，模型会收到“请重新截图后再拾取”的失败结果。

工具执行期间独立每 2 秒调用轻量 `/lease` 续租，不依赖被工具阻塞的轮询；执行前及回执提交前也明确续租。后台页面计时器受限或同步截图阻塞超过 8 秒后，原 owner 在没有新 epoch 接管时可以恢复续租；另一页面接管后旧 owner/epoch 无法恢复。结果先写入 IndexedDB，再续租并回传；租约拒绝时最多重新续租并提交同一回执一次，不重新运行工具。页面切换或停止后不再续租。刷新使旧截图坐标失效的保护继续保留。

工作区提交仍使用 baseRevision 比较。发生其他编辑时保留任务草稿并进入冲突状态，不覆盖正式场景。接受提案使用固定 requestId，并先保存 commitPending；即使数据库已提交而任务行尚未更新就中断，服务重启也会幂等确认原提交。

## API

写请求沿用 `X-Layout-Client: 1` 和同来源校验。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/tasks?sceneId=...&channel=agent` | 当前场景与通道最近任务及对话 |
| GET | `/api/tasks/:id` | 任务状态、工具记录及草稿 |
| POST | `/api/tasks` | 创建并开始任务 |
| POST | `/api/tasks/:id/attach` | 持有或续期浏览器租约；重启后补充密钥 |
| POST | `/api/tasks/:id/lease` | owner/epoch 保持不变的轻量续租，仅返回代次及到期时间 |
| POST | `/api/tasks/:id/result` | 提交工具结果和对应草稿 |
| POST | `/api/tasks/:id/verdict` | accepted 接受、revised 保留草稿调整、rejected 回滚重做 |
| POST | `/api/tasks/:id/retry` | 暂停后重试当前模型请求，需 requestId 及 settings.apiKey（或兼容 apiKey），可更新模型配置、tools/system |
| POST | `/api/tasks/:id/cancel` | 取消后端任务 |

任务查询不返回密钥、模型配置、完整模型输入上下文和工作区撤销日志；用户可见记录、草稿和对比所需的基线文档 before 会返回给本地界面。本服务仍为本地单用户服务，不提供公网账号隔离。

## 验证

- 后端模拟模型：断开页面后推理继续、工具租约、重复回执、服务重启、等待裁决恢复、提交中断恢复、取消与版本冲突。
- 真实 Edge + 本地模拟 SSE 模型：AI 编辑输入后刷新、工具回执丢失后刷新、待确认时再次刷新，对话和草稿恢复，接受后物体只移动一次。
- 使用临时场景与数据库，不调用用户付费模型，不修改真实测试场景。

运行：在 `src/` 执行 `npm.cmd run test:backend`、`npm.cmd run test:backend-browser`、`npm.cmd run test:coagent` 和 `npm.cmd run build`。
