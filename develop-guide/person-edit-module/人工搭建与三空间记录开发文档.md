# 3D-Layout 人工搭建与三空间记录开发文档

## 1. 目标与现状

人工搭建插件从现有人工编辑模块扩展。用户可以从空场景开始创建地形、选材、摆放与调整物体、布置灯光，保存后继续编辑。录制开启时，同一次搭建会话还应产出编辑事件空间、视口可见性场和物体可见性空间，用于回放并为 coAgent 的意图推断提供证据。

| 能力 | 当前基础 | 需要补充 |
| --- | --- | --- |
| 新建与保存 | 顶栏可创建空场景，宿主已有场景保存与编辑历史 | 空场景中的搭建引导和地形创建入口 |
| 模型资源 | 已有全局模型目录、分类、尺寸和关键词检索 | 面向人工的素材浏览、预览与视口放置 |
| 人工编辑 | 已有单选、变换手柄、数值编辑、复制、删除和聚焦 | 对象列表、连续放置、多选和层级 |
| 地形与材质 | 宿主支持地形数据与渲染，内置草地、沙地、岩石、雪地。地表现有实现每块地形最多四层 | 人工地形创建、图层选择、笔刷及自定义材质入库 |
| 灯光 | 点光源和聚光灯已可创建、编辑、撤销、保存和恢复。渲染由宿主负责 | 后续统一到视口落点放置，并增加环境调光入口 |

现有实现可查阅[人工编辑面板](../../src/modules/editor/EditorPanel.tsx)、[宿主事务](../../src/core/edit.ts)、[场景数据定义](../../src/core/types.ts)、[模型检索](../../src/core/modelSearch.ts)和[地形说明](../../src/modules/terrain/README.md)。

## 2. 人工搭建功能清单

### 2.1 工作台与职责

| 位置 | 功能 |
| --- | --- |
| 左侧 | 放置、变换、创建地形和笔刷等搭建工具。场景对象列表与视口选中状态联动，后续升级为对象树。 |
| 中央 | 三维视口负责浏览、拾取、预览落点、绘制笔刷范围和显示变换手柄。 |
| 右侧 | 素材库、检查器和历史共用现有侧栏。素材库展示可用资源，检查器编辑已选对象，历史显示已提交的操作。 |

素材库作为独立的浏览模块，复用现有全局模型目录，向搭建插件提供选中的模型引用。搭建插件处理落点预览与确认，再通过宿主编辑入口写入实例。地表四种内置预设先从地形检查器选用。自定义材质入库后，在同一素材库增加「材质」分类。

宿主负责场景数据、渲染、对象 ID 的唯一性、事务、保存及恢复。人工搭建插件负责面板、快捷键、拾取反馈和编辑预览。地形采样、贴地、散布等可复用计算由公共能力提供，人工与 AI 入口各自提交事务。已保存对象通过宿主渲染，关闭插件后仍可加载和显示。[公共编辑能力边界](../公共编辑能力边界与迁移方案.md)

### 2.3 完整搭建版

按场景制作流程实现以下能力，每一项均通过宿主事务纳入保存与撤销。

| 功能 | 开发要求 |
| --- | --- |
| 基础形体与灰盒 | 创建方块、平面、圆柱和空组，支持按世界尺寸搭墙、台阶和平台。用正式模型替换占位物时保留对象 ID，可选择适配原尺寸。 |
| 多选与精确布局 | 提供框选、多选变换、世界／局部坐标、正交与俯视视角、表面吸附、对齐、等距分布及阵列复制。批量操作可预览并一次提交。 |
| 场景层级 | 对象树支持搜索、重命名、分组、父子关系、锁定和隐藏。更换父级时默认保持世界变换，移动父组时带动子物体。编辑临时隐藏与场景可见属性分别保存。现有平铺资产加载为根节点。 |
| 地形雕刻和绘制 | 提供抬高、压低、压平、平滑笔刷与范围预览。图层可选择内置预设或自定义材质，调整平铺尺寸并局部涂抹。地形高度图可用于创建实际起伏，材质高度贴图用于材质过渡与表面细节。 |
| 植被和道具散布 | 从模型库选择树、石块和灌木，设置刷子半径、密度、最小间距、坡度范围及随机朝向。支持预览、局部擦除和单实例编辑。地形修改后可将所选物体重新贴地。 |
| 模型与材质导入 | 单个静态 GLB 支持校验、尺寸与朝向预览、落地原点调整和入库。材质页支持可平铺的基础色及可选法线、粗糙度等贴图。检查器可独立调整实例材质。可复用现有导入插件的校验和坐标归一化能力。[现有导入流程](../../plugins/threejs-interchange/README.md) |
| 可复用组合 | 将一组带相对变换的对象保存为素材组合，例如火盆、桌子和三把椅子。每次放置复制一组实例，子物体可以继续调整。 |
| 环境与出图 | 开放天空、背景、HDRI、主光方向和强度。灯光支持点击视口落点创建。场景相机可从当前视角新建，支持调整视场角、切换预览和输出截图。 |

## 3. 三空间记录方法

### 3.1 录制开关与会话边界

人工搭建工具栏提供一个「录制」开关，默认关闭。打开时为当前场景创建一场新会话，保存初始场景和起始相机样本，开始采集编辑事务与视口参数。开启期间显示录制状态和已录时长。

关闭时按当前场景最后一个已提交的版本补记结束样本，停止采集并写完待保存的记录。原始数据落盘后显示「已保存」。若停止录制时打开了「计算可见性空间」，保存后会离线计算并显示进度。用户可以继续搭建，也可以再次打开开关开始一场独立会话。每次开启使用新的会话 ID 和独立目录。切换场景前先结束当前录制，进入新场景后由用户重新打开开关。

### 3.2 一次录制的共同数据与存放位置

三空间共享场景世界坐标 `XYZ`（米，`+Y` 朝上）和会话时间 `T`。开始录制时保存初始场景、视口设置、资产引用及可用版本信息，从 `sceneRevision = 0` 开始。后续每次正式场景变化推进版本。编辑事件与相机样本使用同一个单调会话时钟和全局序号，解决时间戳相同的先后顺序。相机样本还保存对应的 `sceneRevision`，回放时可恢复当时的几何、世界变换和可见状态。

录制由本地宿主服务保存，默认目录为 `<LAYOUT_ROOT>/.data/recordings/<sceneId>/<sessionId>/`。`LAYOUT_ROOT` 沿用现有服务的数据根目录配置，默认指向 3D-Layout 项目根目录。`.data/` 已被 Git 忽略。一个场景可以有多次录制，每次会话独立于 `scene.json`、场景撤销栈和其他会话。复制会话目录可备份记录，回放还需要相应版本的模型与材质资源。[现有数据根目录配置](../../server/README.md)

打开开关时创建目录并保存会话信息和初始场景。录制期间分批追加编辑事件和相机样本，关闭时写入最后一批数据并标记采集结束，减少页面异常退出造成的记录丢失。异常中断的会话保留已落盘的数据，标记为「录制中断」。可见性结果分批写回同一会话目录。「录制会话」中可以用原始数据补算或重试。回放加载的资源版本缺失或已变更时，标记受影响样本。

会话界面按当前场景列出录制时间、时长和处理状态，支持打开回放或导出。导出将同一会话目录的文件打包，用户可以自行选择存放位置。完成原始录制文件的保存由开关触发。

| 文件 | 用途 |
| --- | --- |
| `session.json` | 会话 ID、场景 ID、格式版本、开始与结束时间、时长、采集与分析状态、单位、上轴、资源引用与版本、可见性计算配置。 |
| `initial-scene.json` | 初始场景和会影响视口呈现的设置。 |
| `edit-events.jsonl` | 按发生顺序追加的编辑与历史操作。 |
| `viewport-samples.jsonl` | 实际编辑视口的相机样本及其场景版本。 |
| `object-visibility.jsonl` | 以相机样本 ID、场景版本和对象 ID 为索引的计算结果。 |

### 3.3 编辑事件空间

沿用 SceneCrafter 的 `Action–Object–Parameter` 思路，基于宿主编辑事务输出结构化 JSON。事件保存 `eventId`、`seq`、`tMs`、`txId`、`source`、`action`、`parameters`、变更前后场景版本及 `changes`。每条对象变化包含稳定 ID、对象类型和足以回放的 `before`／`after`；三维对象还保留世界位置或范围。移动保留起点和终点，新增的前态为空，删除的后态为空。

- 一次拖拽合并为一个事件，轨迹首版保留提交前后的状态。若后续要分析拖拽途中发生的遮挡，再补与相机对齐的临时变换采样。
- 复制、组移动和散布保留受影响实例的明细。组移动即使只写入了父组变换，也应在导出中提供子物体前后的世界位置，供时空检索使用。
- 地形雕刻记录涉及的区域与高度差量，地表绘制记录权重变化，散布记录新增或擦除的实例。场景级操作保存完整变更，空间定位使用其实际影响范围。
- 撤销和重做追加事件，引用被操作的事务，并记录本次实际应用的变化。场景编辑历史保留交互撤销能力，会话日志额外保留创作顺序，包括之后被撤回的尝试。

建议从宿主「事务确认、撤销、重做」的实际生效点发出记录。放置预览、取消的笔划和数值输入中间态按交互处理。对编辑前后可见性的比较使用稳定的前后场景状态。现有 `history:changed` 可用于刷新界面，录制需要携带实际变化及方向的事件数据。[事务实现](../../src/core/edit.ts)

### 3.4 视口可见性场

在编辑视口相机完成更新后采集参数。每条样本记录 `sampleId`、`seq`、`tMs`、`sceneRevision`、实际视口宽高、相机位置与朝向，以及投影矩阵或等价投影参数，覆盖透视／正交类型、裁剪面及对应视场范围。若编辑模式支持临时隐藏、隔离或渲染层筛选，应记录当时的有效设置。场景相机属于作品数据，录制采集用户实际看到的编辑视口。

首版建议在视口相机变化时约 **10 Hz** 采样，并在录制开始与结束、编辑提交前后、撤销重做前后和视口尺寸变化时额外保留样本。即使相机未动，删树前后的样本也应明确关联两个场景版本。结束后用参数重建 (XYZT) 下的视锥覆盖。需要判断某个世界位置是否被挡住时，再结合相应场景几何做深度或射线查询。可见性表示视口中能够看到的内容，真实注意力由另行采集的行为证据支持。[现有相机与拾取能力](../../src/core/engine.ts)

### 3.5 物体可见性空间

首版采用**录制结束后离屏计算对象 ID 缓冲**。每个采样时刻按场景版本还原几何并挂载相机。使用与视口相同的宽高比，先以约 **320×180（16∶9 时）** 的分辨率做简化渲染。像素写入最前方可见对象的索引，深度测试处理遮挡。所有属于同一实例的网格共用同一个 ID。网格线、变换手柄和灯光图标等编辑辅助件排除在统计之外。计算结束丢弃缓冲，导出每个对象的数值。[Three.js 对象 ID 离屏渲染](https://threejs.org/manual/pages/picking.html)

| 指标 | 计算 |
| --- | --- |
| **画幅占比 (S)** | 整场 ID 缓冲中属于该对象的像素数 ÷ 缓冲总像素数，一次场景渲染可统计所有对象。 |
| **可见比例 (Q)** | 整场缓冲中该对象的可见像素数 ÷ 同一相机单独渲染该对象时、裁剪到当前视口内的投影像素数。首版对编辑对象和重点参照物计算。 |

(Q) 的分母只考虑当前视口内的未遮挡投影。椅子一半出画，留在画面里的部分全部露出时，(S) 下降，(Q) 仍可为 100%。单独投影有像素而整场无像素时，(Q = 0)。明确出画时标记 `out_of_view`，`Q` 留空。小物体或细叶可能在低分辨率下采不到，零像素且无法确认原因的样本标为 `unresolved`，关键帧提高分辨率复算。灯光对象可进入编辑事件空间，其辅助图标不作为对象面积，光源没有自身几何时可见性标记为 `not_applicable`。树叶等使用透明裁切的模型，ID 渲染应保留同样的裁切规则。

导出每条可见性结果时保留 `sampleId`、`sceneRevision`、`objectId`、`status`、`visiblePixels`、`projectedPixels`、`screenOccupancy` 和 `visibilityRatio`。仅计算了画幅占比时，将 `projectedPixels` 与 `visibilityRatio` 留空。首版把低分辨率、采样频率和重点对象范围作为可调整的计算参数。可先用视锥和包围盒筛选候选对象，必要时使用少量射线估计重点对象是否露出。包围盒和射线粗估结果需记明计算方法，便于与像素统计区分。[视锥筛选](https://threejs.org/docs/pages/Frustum.html)

### 3.6 关联和回放

以 `sceneRevision` 复原各相机样本的场景，以 `sampleId + objectId` 查可见性。编辑事件通过时间和变更前后版本找到相邻样本，再按对象 ID 取本次被编辑对象及周围参照物的状态。回放界面点选一次删除时，应能同步看到删除前后画面、相机位置、被删物体和其他物体的可见性变化。coAgent 可利用时空邻近与可见共现生成候选事件组，并结合操作语义和场景上下文推断共同目标。

## 4. 开发顺序与验收

1. **跑通搭建流程。** 在空场景创建地形，从右侧素材库摆入帐篷、树、椅子和篝火。调整位置、删除物体、撤销一次放置，在篝火旁添加暖色点光源。保存并重开，核对场景对象、地表和灯光。
2. **跑通录制回放。** 打开开关后录制初始场景、对象事务和实际视口参数。关闭后检查会话已自动保存，继续编辑时原会话的采集内容保持固定。再次打开开关应产生新目录。重放日志可恢复录制结束时的场景，也能查看撤销前的状态。相机轨迹通过编辑事件前后状态校验。
3. **验证离屏可见性。** 固定视角，删除挡在帐篷前的树，验证帐篷可见性上升。再转动相机让物体部分出画，核对画幅占比与遮挡比例的区别。覆盖完全遮挡、完全出画、细小对象和编辑辅助件的处理。对照少量高分辨率参考帧，并比较录制开关前后的视口流畅度，记录离线分析耗时。
4. **扩展至完整搭建。** 加入灰盒定尺度、地形雕刻、小路涂层、植被散布、路牌导入、整组移动和场景相机。验证旧场景加载、新场景保存重开，并回放一笔地形编辑和一次组移动涉及的几何、对象与可见性变化。

### 汇报版使用入口

在左侧插件栏打开「人工搭建」，也可以在地址后加 `?build=1` 直接进入。人工编辑与人工搭建共用选中状态和宿主历史，同一时间启用一套编辑工具。右侧「素材库」选择模型后在视口点击放置，也可以直接拖入视口。放置时用 `[`、`]` 调整朝向，`Esc` 取消。

在「会话录制」打开录制开关。关闭录制后，原始记录会自动保存。「计算可见性空间」默认关闭，打开时会在保存后启动离屏计算。可在「录制会话」点击「计算可见性」补算或重试。ZIP 包含会话的五个记录文件，回放时使用素材库中的对应资源。

在 `src` 下运行 `pnpm test:backend-browser --build-only --build-real-assets`，可使用素材库中的帐篷、松树、木椅和篝火执行汇报版浏览器验收。

### 完整搭建版操作

- 「创建基础形体」按米输入尺寸。选中灰盒后可从素材库替换成正式模型，保留对象 ID 和所属组，可勾选适配尺寸。
- 在对象树按住 Shift 或 Ctrl 追加选择，也可切换「框选」后在视口框出一组物体。拖到目标组或在检查器改父级，物体保持世界位置。对象组和多选通过共同支点等比缩放。树上的眼睛按钮保存当前编辑视口的临时隐藏，检查器的「场景可见」写入场景。对象树的父节点使用对象组。
- 「批量布局」预览对齐、等距分布与阵列，然后一次应用。俯视、正视及右视使用正交投影。表面吸附可将模型落在现有物体上。放置预览时按住右键左右拖动可固定落点旋转模型，左键确认。选中对象后用视口上方的移动、旋转和缩放工具，或按 `W`、`E`、`R`。
- 左侧「地形笔刷」「植被笔刷」「材质笔刷」各自打开对应工具。材质笔刷可直接选择目标地形、添加和选择图层。素材库的「用于散布」会打开植被笔刷，可继续设置范围、密度、间距和坡度。按住左键拖动，在松开时提交一笔。创建地形时也可用灰度高度图生成起伏。
- 「导入 GLB」校验独立静态模型并预览尺寸、朝向和底部原点。确认入库后在「手工导入」类别找到该模型。可把所选物体及子物体保存为「素材组合」，重复放置时每份都有独立对象 ID。
- 在 `src` 下运行 `pnpm test:backend-browser --build-only --build-real-assets --full-build` 进行浏览器验收。
- 「人工搭建」左侧面板顶部可手动「保存场景」。
