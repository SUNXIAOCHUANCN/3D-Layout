# 实施总计划与代码导航

## 1. 实施边界

本修订不替换 LangGraph，不改变编辑器为场景事实源的原则，不为每区复制场景，不引入完整桌面 Computer Use，不实现跨区搬移。新增服务通过现有 WorkflowContext、RenderPort、EditorReadPort/EditorWritePort 和 runtime 装配接入。

本包所写新增文件名和类型是建议；允许重用已有文件，但须保持明确职责和测试边界。所有源码路径均相对仓库根目录。

## 2. 阶段与依赖

| 阶段 | 范围 | 前置 | 交付 |
| --- | --- | --- | --- |
| P0 | 碰撞策略复核、基线保护 | 无 | 保留已完成改动，确认配对范围与日志 |
| P1 | 实时状态、任务数量、权限、修复 | P0 | 状态与修复闭环，见 04 |
| P2 | 区域相机、图片更新、截图点选 | P1 的状态接口 | 可观察可定位，见 05 |
| P3 | 验收保留与整轮撤销 | P1 的写入记录 | 失败结果可保留可撤销，见 06 |
| P4 | 分区文件、加载核对、保存一致性 | P1 归属规则，接入 P3 提交/撤销 | 可跨重启复用，见 07 |
| P5 | 全链路验收与文档回填 | 全部 | 见 08 |

P2 和 P3 在接口稳定后可以独立开发，但不要同时无协调地改 contracts、runController、registry。P4 的文件读写可先做，最终归属逻辑必须复用 P1，不能形成第三套成员算法。

## 4. P0：保留改动 1，补充诊断配对范围

用户已有实现包含 `no_collision.basis` 和规划原文依据校验。不要为了兼容新任务 schema 丢掉这些校验，也不要恢复默认零碰撞规则。

检查 `rendering/geometry.ts` 是否仍将所有对象合并全量配对。如仍存在，改成：

```text
targets = 本任务当前存在的新增/修改/目标对象
statics = 当前场景中其他相关对象
检查 targets×targets（去重）和 targets×statics
不检查 statics×statics
```

保留现有 ground-contact 行为并用测试约束，不要顺便宣称解决所有地形支撑语义。mesh intersection 和视觉不合理不是同义词。

普通诊断可按附近包围盒筛选环境，硬性“与所有对象不相交”不能因候选截断就返回 clear。超过几何预算、64 对象限制等应返回 unknown/覆盖不足，或分批检查，不能静默忽略对象。跨区环境可只读参与检测。

## 5. 跨模块一致性规则

1. 只有编辑器快照提供对象实际变换，任务记录保存归属和操作历史，不复制一份可独立修改的场景。
2. run 开始冻结分区；本轮创建对象动态登记。新分区恢复不能影响活跃 run。
3. 所有授权和数量检查应与实际写入在同一串行作业中完成；不要在 `await` 前验证、排队后直接执行过期结论。
4. 写入成功后、返回工具结果前完成登记；幂等缓存与重复回执不得重复消耗名额。
5. 用户可见结果由结构化记录产生，不采用 executor 自述数量作为事实。
6. 判定 fail/uncertain 保持原样；新增 retained 状态不覆盖判定结果。
7. 相机工作状态、选中目标不写入全局用户 selection，也不进入对象编辑历史。
8. 分区保存是 IO，不启动对象编辑事务，不隐式保存未落盘的场景修改。

## 6. 契约兼容策略

- 新生成 add 任务要求结构化 creationTarget；旧测试、日志重放和 fake 必须明确迁移，不从自然语言 objective 猜数字。
- 推荐 UnitTask 增加可选字段以兼容旧数据的解析，新计划语义校验强制 add 必填。旧 add 计划若需要重新执行，重新规划或显式转换后执行，不自动无限新增。
- 新增 tool name、ToolError、phase、event 时，搜索其全部穷举分支、fake 和模型工具 schema；仅新增 TS 联合类型不会自动更新 UI。
- RenderPort 新增拾取能力同步 FakeRender。使用可选能力时必须返回明确 unavailable，而不是空命中伪装正常。
- EditorWritePort 提交/撤销回执变更同步真实与 FakeEditor；不能只在真实编辑器走特别宽松的旁路。
- 分区文件 schemaVersion 与 partitionVersion 分离：前者控制迁移，后者表示用户分区内容变化。

## 7. 首版暂缓项

- 鼠标拖动物体、操作 gizmo、点击地面直接摆放。
- 无条件自动识别透明材质每个像素的真实可见性；首版按验证过的拾取规则处理并说明限制。
- 跨后续编辑的选择性撤销、按区域拆事务。
- 自动恢复到上次未结束的 Agent 任务、跨重启恢复活跃事务。
- 自动合并两个用户同时改的分区、完整分区版本历史库。
- 模型超时后全部情形默认保留、卸载时默认保留等取消策略扩展（首版只改正常验收结果）。
