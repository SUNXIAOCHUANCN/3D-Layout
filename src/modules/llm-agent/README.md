# LLM Agent 实验插件

默认聊天传输已接入共享后端任务服务，刷新后可恢复对话与草稿。下文的每轮文件日志与浏览器本地循环描述适用于旧传输；默认任务记录现在保存于 SQLite `ai_tasks`，详见 `develop-guide/AI任务持久化与重连.md`。

本模块从 `modules/agent` 的现有 LLM 实现建立，单独装配到侧栏“LLM Agent 实验”。它与老插件互斥启用，不改写老插件代码。两者共用场景编辑引擎和浏览器中的模型配置。

当前实现：原有对象编辑工具、自由工具选择的系统提示词、自定义相机截图和关联拾取、参数化及自定义高度场地形、实例级 PBR 材质、每轮自动记录，以及多行输入和少量状态修正。

工具循环不设轮数上限，持续回传工具结果和保留对话历史，直到模型不再调用工具、用户停止或运行出错。截图仍只保留最近一批附图。框架不自动压缩文本历史，实际上下文容量由所用模型及服务决定；运行日志中的 `maxRounds: null` 表示无限制。

自动记录位于本模块 `logs/<runId>/`，包含开始前场景、模型可见配置与工具 schema、模型请求及响应、工具调用、截图 PNG、事务与保存事件、结束状态和运行后场景。日志服务不可用时不会开始新运行；开发或预览服务提供写入接口，纯静态部署不提供。

Python 工具通过本地 Docker 执行，需提前准备 `python:3.12-alpine` 镜像；插件不会自动下载镜像，也不会退回宿主机 Python。运行开始时若 Docker 或镜像不可用，该轮不会向模型开放 `python.execute`，并在界面与日志中注明。容器使用无网络、只读文件系统、无特权、内存和超时限制；代码通过标准输入传入，`inputs` 提供 JSON 输入，JSON 可序列化的 `result` 变量与标准输出返回给模型。包含 `width`、`depth`、`samplesX`、`samplesZ` 和 `heights` 的结果可以用 `resultId` 交给 `terrain.create_heightfield`，引用仅在本轮运行内有效。镜像和容器运行条件需要在目标环境验证。

尚未实现：文件形式的 Python 生成产物、纹理生成及设计文档中的全部材质工具、UI 和实验记录字段。当前地形高度数据直接保存在场景内；材质对单个实例的所有网格生效，不支持材质槽及纹理。不要将当前模块当作完整实验环境。

详细设计见 `develop-guide/LLM插件升级设计.md`。
